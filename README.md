# LFINFO Hours

SaaS de gestion du temps pour les PME et leurs équipes de terrain.

Le [cahier des charges fonctionnel et technique](LFINFO_HOURS_CAHIER_DES_CHARGES.md)
constitue la source de vérité du projet. Il doit être lu intégralement avant
toute modification ; ses instructions Codex et son ordre de jalons s'appliquent.

Le JALON 0 initialise le dépôt sur la branche principale `main`, les exclusions
Git et la documentation fondatrice. Aucun code applicatif n'est encore présent.
La fondation technique relève du JALON 1, à réaliser sur demande distincte.

Ne jamais versionner de secret. Les futurs fichiers `.env.example` doivent
utiliser des valeurs factices explicites ou `A_REMPLIR` pour les valeurs inconnues.
